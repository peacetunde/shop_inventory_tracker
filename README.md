# Small-Shop Inventory Tracker

A lightweight, clean, and responsive web application designed for small-shop owners to track inventory, stock levels, and selling prices directly in the browser with zero server setup.

## Features
- **Add Products**: Record Product Name, Quantity in Stock, and Selling Price.
- **Persistent Storage**: All inventory data is saved in browser `localStorage` and persists across page reloads.
- **Stock Indicators**: Visual stock status badges (In Stock, Low Stock, Out of Stock).
- **Edit & Delete**: Easily update item details or remove products with confirmation dialog protection.
- **Real-Time Search**: Quickly filter products by name.
- **Overview Metrics**: Live totals for total unique products, units in stock, and overall inventory dollar value.
- **Mobile Responsive**: Fully optimized for phone screens and desktop browsers.

## Tech Stack
- HTML5
- CSS3 (Responsive Grid/Flexbox)
- Vanilla JavaScript (ES6+, LocalStorage API)

## Getting Started
Simply open `index.html` in any modern web browser. No installation, server, database, or build steps required.
